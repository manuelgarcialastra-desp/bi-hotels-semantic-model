# Checklist de cierre

Usa esta lista antes de compartir un resultado o dar por cerrado el trabajo.

- [ ] `CONTEXT.md` refleja la pregunta y el entregable real.
- [ ] Las fuentes usadas estan inventariadas en `setup/source_inventory.md`.
- [ ] Los datos crudos quedaron separados de intermedios y finales.
- [ ] Los joins, filtros y supuestos relevantes estan explicados en `docs/notes` o `docs/decisions`.
- [ ] El SQL y los scripts necesarios para reconstruir el analisis estan guardados.
- [ ] Los outputs finales estan en `output/` o `presentaciones/final`.
- [ ] Hay una nota clara sobre riesgos, limitaciones o dudas abiertas.
- [ ] Otra persona podria reconstruir el trabajo leyendo la carpeta.
- [ ] Si corresponde, el tiempo del analisis fue registrado con la skill del equipo.
